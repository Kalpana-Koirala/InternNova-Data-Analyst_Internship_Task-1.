# InternNova-Data-Analyst_Internship_Task-1.
## Task 1: Student Information Program
Collects a student's name, college, and branch via input() and displays them in a formatted summary.

## Task 2: Data Types Demo
Declares variables of different types (int, float, str, bool) and uses type() to print each one's data type.

## Task 3: Calculator Program
Takes two numbers from the user and performs addition, subtraction, multiplication, division, and modulus — with a check to avoid division by zero.

## Task 4: Grading System
Uses if/elif/else to assign a letter grade (A/B/C/Fail) based on a single subject's marks, then repeats the logic using the average of five subjects for an overall grade.

## Task 5: Loops
Demonstrates three loop patterns: printing numbers 1–20 with a for loop, generating a multiplication table for a user-given number, and printing even numbers up to 50 using a while loop.

## Task 6: Functions
Defines two functions — one to calculate the square of a number, another to calculate the average of three numbers — and calls them with user input.

## Task 7: Strings & Collections
A multi-part task covering core data structures:

- Strings : upper(), lower(), replace(), find()
- Lists : append(), remove(), sort()
- Tuples : creation and indexing
- Dictionaries : storing and updating student info (roll no, name, age, course, marks)
- Sets : add(), remove()

## Task 8: File Handling
Writes a short student introduction to introduction.txt, then reopens the file to read and display its contents.

## Task 9: Student Record Management System
A menu-driven program that manages student records using a list of dictionaries. It offers five operations in a loop until the user exits:
- Add Student: collects name, age, and major, and appends a new dictionary to the students list
- Display All Students: loops through the list and prints each record in a numbered, formatted layout
- Search Student by Name: filters the list with a case-insensitive match and prints any results found
- Delete Student: finds a matching record by name and removes it with .remove()
- Exit: breaks out of the menu loop and ends the program
Data is stored in memory only (the students list resets each time the program runs), and all four core operations reuse the same list of dictionaries as the underlying data structure.
